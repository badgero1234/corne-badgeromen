# Corne Keyboard - Multi-OS Layout Reference

## Quick Access Guide

| Action | How to Access |
|--------|---------------|
| **Numbers & F-Keys** | Hold LEFT far thumb (LOWER) |
| **Symbols & Media** | Hold RIGHT middle thumb (RAISE) |
| **Switch OS Mode** | Hold RAISE + bottom-right corner → then tap Q/W/E/R |
| **Gaming Mode** | Settings → tap R position (or double-tap RAISE) |
| **Return from Gaming** | Double-tap middle right thumb |

---

## Layer 0: MAC BASE (Default)

**When to use:** When connected to a Mac device

```
┌──────┬──────┬──────┬──────┬──────┬──────┐       ┌──────┬──────┬──────┬──────┬──────┬──────┐
│ TAB  │  Q   │  W   │  E   │  R   │  T   │       │  Y   │  U   │  I   │  O   │  P   │ CMD  │
│      │      │      │      │      │      │       │      │      │      │      │      │ (⌘)  │
├──────┼──────┼──────┼──────┼──────┼──────┤       ├──────┼──────┼──────┼──────┼──────┼──────┤
│ CTRL │  A   │  S   │  D   │  F   │  G   │       │  H   │  J   │  K   │  L   │  ;   │  '   │
├──────┼──────┼──────┼──────┼──────┼──────┤       ├──────┼──────┼──────┼──────┼──────┼──────┤
│SHIFT │  Z   │  X   │  C   │  V   │  B   │       │  N   │  M   │  ,   │  .   │  /   │ ESC  │
└──────┴──────┴──────┼──────┼──────┼──────┤       ├──────┼──────┼──────┼──────┴──────┴──────┘
                     │LOWER │BKSP  │ SPC  │       │ ENTER│RAISE │ ALT  │
                     │      │      │      │       │      │ tap2x│      │
                     └──────┴──────┴──────┘       └──────┴──────┴──────┘
```

**Key Shortcuts:**
- Cmd+C/V/X = Copy/Paste/Cut (Cmd in top-right corner + letter)
- Cmd+S = Save
- Cmd+F = Find
- Cmd+Tab = App Switcher
- Alt+Tab = Switch windows (Alt on far right thumb)

```

│ TAB  │  Q   │  W   │  E   │  R   │  T   │       │  Y   │  U   │  I   │  O   │  P   │ BKSP │
├──────┼──────┼──────┼──────┼──────┼──────┤       ├──────┼──────┼──────┼──────┼──────┼──────┤

├──────┼──────┼──────┼──────┼──────┼──────┤       ├──────┼──────┼──────┼──────┼──────┼──────┤
│SHIFT │  Z   │  X   │  C   │  V   │  B   │       │  N   │  M   │  ,   │  .   │  /   │ CTRL │
└──────┴──────┴──────┼──────┼──────┼──────┤       ├──────┼──────┼──────┼──────┴──────┴──────┘

                     └──────┴──────┴──────┘       └──────┴──────┴──────┘

**Gaming Optimizations:**
- **ESC** on left home row for quick menu access
- **SHIFT** on pinky for running
- **CTRL** on right bottom corner for crouching
- **ALT** on left thumb for abilities
- **G_RSE** hold for numbers/F-keys (weapons/abilities)

**How to Exit:** Double-tap right middle thumb (toOS) → returns to Mac layer

**How to access:** Hold LEFT middle thumb

```
┌──────┬──────┬──────┬──────┬──────┬──────┐       ┌──────┬──────┬──────┬──────┬──────┬──────┐
│  `   │  1   │  2   │  3   │  4   │  5   │       │  6   │  7   │  8   │  9   │  0   │ DEL  │

**Development Keys:**
- **F1** = Help / Quick fix
- **F2** = Rename symbol (VSCode/IntelliJ)
- **F3** = Find next
- **F5** = Debug / Run

- **F7** = Build
- **F8** = Step over (debugging)
- **F9** = Breakpoint toggle
- **F10** = Step into
- **F11** = Fullscreen / Step out
- **F12** = Go to definition

**Navigation:**
- Arrow keys for cursor movement
- Home/End for line start/end
- Page Up/Down for scrolling

## Layer 5: RAISE (Symbols + Media + Volume)

**How to access:** Hold RIGHT middle thumb

```
┌──────┬──────┬──────┬──────┬──────┬──────┐       ┌──────┬──────┬──────┬──────┬──────┬──────┐
│  ~   │  !   │  @   │  #   │  $   │  %   │       │  ^   │  &   │  *   │  (   │  )   │ DEL  │
├──────┼──────┼──────┼──────┼──────┼──────┤       ├──────┼──────┼──────┼──────┼──────┼──────┤
│      │ MUTE │ VOL- │ VOL+ │      │      │       │  -   │  =   │  [   │  ]   │  \   │  "   │
├──────┼──────┼──────┼──────┼──────┼──────┤       ├──────┼──────┼──────┼──────┼──────┼──────┤
│      │ PREV │ PLAY │ NEXT │  <   │  >   │       │  _   │  +   │  {   │  }   │  |   │SETNG │
└──────┴──────┴──────┼──────┼──────┼──────┤       ├──────┼──────┼──────┼──────┴──────┴──────┘
                     │      │      │      │       │      │ HOLD │ ALT  │
                     └──────┴──────┴──────┘       └──────┴──────┴──────┘
```

**Symbols for Coding:**
- **Top row:** Shifted numbers (!, @, #, $, %, ^, &, *, (, ))
- **Middle row:** Math/logic operators (-, =, [, ], \, ")
- **Bottom row:** Shifted operators (_, +, {, }, |)
- **Special:** < > for comparisons

**Media Controls:**
- **MUTE** = Toggle mute
- **VOL-/VOL+** = Volume down/up
- **PREV/PLAY/NEXT** = Music controls

**Access Settings:** Hold RAISE layer + tap bottom-right corner key

**Note:** ? (question mark) is available via Shift+/ on base layer

## Layer 7: SETTINGS (OS Selection + Bluetooth)

**How to access:** Hold RAISE (right middle thumb) + tap bottom-right corner key

```
┌──────┬──────┬──────┬──────┬──────┬──────┐       ┌──────┬──────┬──────┬──────┬──────┬──────┐
│BTCLR │ BT0  │ BT1  │ BT2  │ BT3  │ BT4  │       │      │      │      │      │      │      │
├──────┼──────┼──────┼──────┼──────┼──────┤       ├──────┼──────┼──────┼──────┼──────┼──────┤
│ MAC  │ WIN  │LINUX │ GAME │      │      │       │      │      │      │      │      │      │
├──────┼──────┼──────┼──────┼──────┼──────┤       ├──────┼──────┼──────┼──────┼──────┼──────┤
│      │      │      │      │      │BTLDR │       │BTLDR │      │      │      │      │      │
└──────┴──────┴──────┼──────┼──────┼──────┤       ├──────┼──────┼──────┼──────┴──────┴──────┘
                     │      │      │      │       │      │      │      │
                     └──────┴──────┴──────┘       └──────┴──────┴──────┘
```

**Bluetooth Pairing:**
- **BTCLR** = Clear all Bluetooth pairings
- **BT0-BT4** = Select Bluetooth profile (0-4)
  - Profile 0 = Device 1 (e.g., Mac)
  - Profile 1 = Device 2 (e.g., Windows PC)
  - Profile 2 = Device 3 (e.g., Linux machine)

**OS Mode Selection:**
- **MAC** (A position) = Switch to Mac base layer
- **WIN** (S position) = Switch to Windows base layer
- **LINUX** (D position) = Switch to Linux base layer
- **GAME** (F position) = Lock to Gaming layer

**System:**
- **BTLDR** = Enter bootloader (for flashing firmware)
  - **Left side:** Bottom row, 2nd from right (T position on base layer)
  - **Right side:** Bottom row, far left (Y position on base layer)
  - **Much safer** - won't accidentally trigger when accessing Settings!

## Quick Tips

### Muscle Memory Guide:
1. **Same position = same action** across OS layers
   - Copy/paste/cut always use top-right corner (Cmd on Mac, Ctrl on Win/Linux)
   - Your muscle memory is preserved across all operating systems!

2. **Home row modifiers**
   - Left home row = Tab, GUI/Win/Super, Shift
   - Right top corner = Primary modifier (Cmd/Ctrl)
   - Never have to reach far for modifiers

3. **Thumb cluster pattern**
   - **Left:** LOWER (hold), BACKSPACE (tap/hold), Space
   - **Right:** Enter, RAISE (hold/double-tap for gaming), ALT

### Most Common Actions:
- **Backspace:** Middle left thumb (can hold to delete repeatedly!)
- **Numbers:** Hold far left thumb + top row
- **F-keys:** Hold far left thumb + home row
- **Symbols:** Hold right middle thumb + press symbol
- **Volume:** Hold right middle thumb + press A/S/D
- **ALT shortcuts:** Far right thumb + other key
- **Switch OS:** Hold RAISE + bottom-right corner → then Q/W/E
- **Gaming mode:** Double-tap RAISE

### Learning Path:
1. Start with Mac/Windows base layer - learn the feel
2. Practice LOWER (numbers/F-keys) - you'll use this constantly
3. Add RAISE (symbols) - essential for coding
4. Finally explore Settings for OS switching
